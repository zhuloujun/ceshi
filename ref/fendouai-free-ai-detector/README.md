# Free AI Detector

A static landing page for the Lynote free AI detector. It explains the open
two-level detection method, the sentence-level response contract, and how to
read a report.

This Space does **not** run the model. It is the public page only.

- **Full product** (paste, upload, sentence-level review): [lynote.ai/ai-detector](https://lynote.ai/ai-detector)
- **Open-source method and training pipeline**: [github.com/lynote-ai/ai-text-detector](https://github.com/lynote-ai/ai-text-detector)

A detector score is a probabilistic signal, not proof of authorship. Do not use
one alone for disciplinary, legal, or moderation decisions.
