# 模型更新记录（换模型前必须在固定的考试卷上胜过线上版本）

做法参照"持续适应 / 有审计的模型更新"（Continual Adaptation and Audited Model Updating，2026）：
新模型只是"候选"，在同一批没参与训练的真人与 AI 样本上，检出率不降、误判率不升，才替换线上版本；否则保留线上版本，并记下原因。

## 2026-10-25：找到"越训练越差"的原因，改用"或"规则；v19 对比

原因：校准集里的真人样本大部分是 MAGE 网页短段，新模型（v17 / v18）给这些短段的分数普遍偏高（第二分类器 > 0.9 的比例从 3.5% 升到 17%），
校准时为了守住误判率只好把阈值抬高，结果整体漏判变多。其实单看第二分类器，它比四个特征的组合排得更准（论文考卷 AUROC 0.9987 对 0.9899）。
改法：第二分类器分数 ≥ t **或** 组合分数 ≥ 阈值 就判为 AI，t 和阈值在同一误判率预算下交叉验证搜索。上线后（v14）：论文段落检出 94.7% → 99.1%，
小说 93.6% → 97.9%，用户提供的 AI 短篇 93.5% → 100%，误判率没有上升。

v19（Kaggle，加了 nf_ AI 非虚构、Claude 论文、ChatGPT 第一 / 二册、Gemini、更多真人教程书）用同样的"或"规则、同一份考卷对比：

| 考卷（同一份；AI 检出 / 真人误判） | v14（线上） | v19 |
|---|---|---|
| 国产模型论文段落 | 99.1% / 4.2%（AUROC 0.9931） | 99.3% / 3.6%（0.9912） |
| 当代小说 | 97.9% / 3.2%（0.9924） | 100% / 2.8%（0.9895） |
| MAGE GPT-4 | 93.3% / 8.0%（0.9836） | 93.3% / 10.0%（0.9861） |
| 改写过的 GPT-4 | 71.7% / 8.7%（0.9085） | 70.5% / 8.0%（0.906） |
| 英文学术论文（论文校准） | **98.5% / 2.7%**（0.9987） | 99.1% / 3.8%（0.9973） |
| 用户提供的国产模型短篇（论文校准） | **100%** | 93.3% |

结论：保留 v14。v19 在小说、论文段落上略好，但网站上最多的英文学术论文误判率升高（2.7% → 3.8%，arXiv 真人 9%），用户短篇漏判增加，整体没有明显更好。

## 2026-10-26（续）：真人畅销小说误判 → 英文孤立段落保护（engine 7.5）

v14 在用户提供的真人小说（Sparks）上逐段误判 17%（60 段中 9 段）。原因：这些段落 Fast-DetectGPT（中位 0.68，和 Claude 写的 0.66 一样）、
Binoculars、通用分类器、第二分类器全都偏高——畅销书文字简单流畅，而且可能被语言模型"见过"（与美国宪法、圣经被零样本检测器判成 AI 同理）；
单看一段分不出来，但整本书第二分类器中位数只有 0.09。中文早有"孤立段落保护"（7b），英文没有。
新规则：同一篇英文作品 ≥ 6 段、第二分类器整篇加权中位数 < 0.3、过线文字 < 20%，其中综合分与第二分类器都 < 0.95 的过线段落不计入，标"接近阈值"。
按已提交得分模拟：Sparks 9 段误判 → 1 段；纯 AI 作品不受影响（第二分类器整篇中位数都 ≥ 0.9）。离线验收（AI 长文 100%、公版小说 0%、插入 2 段 ChatGPT 的混合文档）前后一致。
另：v20 在 Sparks 上的 3% 有一部分来自训练数据里同一本书的其他段落（同书泄漏），不能直接当作泛化能力。

## 2026-10-26（续）：真人文章里夹入的 AI 段落——两次尝试都不上线（分支 feat-1026w）

现象：公版小说《失落的世界》里插入 2 段 ChatGPT（约 8% 篇幅）只测出 2%；插入 Claude、Gemini 各 1 段测出 0%。
原因：AI 段落（60–90 词）与前后真人段落合成约 1000 字的检测段，整段分数被稀释（8%–10%）；逐句复查窗口要求综合分 ≥ 0.95，
而这几段单独检测综合分只有 0.90–0.95（第二分类器 0.95–0.96，单独检测全部 100%）。
1）窗口按原文段落切：混合文档 2% → 0%，无效。
2）英文窗口在第二分类器 ≥ 0.95 时综合分门槛放宽到 0.85：混合文档 2% → 7%、0% → 4%，但真人书节选误判同时上升——
   AP 生物 4% → 11%、《Delivering Happiness》41% → 57%、《Coincidence》17% → 24%、《Doc》0% → 7%。代价大于收益，不上线。
另发现：真人商业回忆录《Delivering Happiness》（2010）节选线上就有 41%、小说《Coincidence》17%，已加入真人书库供下一轮训练。
